02

GitHub Actions 버튼 하나

저장소 Secrets에 GEMINI_API_KEY를 넣고 Actions → 🎬 Make film에서 회사 이름만 입력하면 Pages에 공개돼요.

03

API 키 없이 Gemini 앱으로

scripts/prompts.py가 이미지·음악 프롬프트를 출력해요. Gemini 앱에서 만들어 assets/에 넣고 빌드하세요.
